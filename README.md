# weather

Minimal CLI weather script using [wttr.in](https://wttr.in).

Uses [ip-api.com](http://ip-api.com) to get your current location (city name + coordinates). Weather data from [wttr.in](https://wttr.in).

## Usage

```
./weather.sh          current location, full forecast
./weather.sh -s       current location, one-line format
./weather.sh London   London full forecast
./weather.sh London -s  London one-line format
```
